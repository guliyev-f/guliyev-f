Hi, I'm Farid — a data and automation engineer with a background in systems design, database architecture, and building integrations that connect different parts of a business together.

Most of my work revolves around taking messy, manual processes and turning them into clean, automated workflows. I spend a lot of my time working with Python, SQL, and various APIs — whether that means designing databases from scratch, setting up ETL pipelines, or wiring together systems so they talk to each other without someone having to copy-paste things between tools.

I have also been working with AI and large language models more recently, building things like retrieval-augmented generation pipelines, AI agents, and data extraction tools that use multi-modal LLMs to process and classify information at scale.

This repository is where I keep the projects I have built — they cover areas like data engineering, machine learning pipelines, API integrations, and automation tools. Each one is a complete, end-to-end piece of work, from initial problem scoping through to a working implementation. Feel free to browse through the [Projects](./Projects) folder to see what I have been working on.
